# dangerouslaser
Laser engraving G-code generator

Supports loading SVG and raster images and generating gcode which utilizes the M3/M5 commands to turn the laser on/off and S (spindle speed) to control the laser PWM duty cycle.

# Features

* Built-in preview/simulator.
* Variety of settings for sizing and orientation.
* Both grayscale and dithering methods for raster images.
* Sample files including a power calibration sample.
